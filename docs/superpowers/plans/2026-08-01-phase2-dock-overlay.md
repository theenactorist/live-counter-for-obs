# Phase 2: Dock and Overlay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The two pages the operator actually uses — the control dock and the transparent overlay — fully functional against OBS's websocket, buildable to two self-contained `file://`-loadable HTML files, with the engine wired to a single authoritative session controller.

**Architecture:** The dock page owns everything: `SessionController` composes the Phase 1 engine + `AutoTimer` + storage + the bus, processes commands serially, persists after every change, and broadcasts state. The overlay is a pure renderer keyed off those broadcasts. Both pages connect to obs-websocket (`BroadcastCustomEvent` = bus, persistent data = storage mirror). Everything testable headless: protocol/controller via vitest against a mock obs-websocket server, UI via Playwright against the built bundles.

**Tech Stack:** TypeScript strict · Vite + vite-plugin-singlefile (two entries → `dist/dock.html`, `dist/overlay.html`, fonts inlined) · vanilla TS + a ~40-line reactive store (no framework) · vitest + `ws` mock server · Playwright (chromium) · @fontsource/inter + @fontsource/oswald (OFL, licenses shipped).

## Global Constraints

- Both bundles run from `file://`: single-file output, no runtime network except `ws://127.0.0.1:<port>`; fonts inlined as data URIs with OFL license files copied to `dist/`.
- obs-websocket 5.x protocol: Hello(op 0) → Identify(op 1, auth = `base64(sha256(base64(sha256(password+salt))+challenge))` via `crypto.subtle`) → Identified(op 2); requests op 6 / responses op 7 correlated by `requestId`; events op 5. Event subscriptions for Phase 2: `General | Inputs` = 9.
- Bus envelope (locked): `{ app: 'live-counter', v: 1, source: 'dock'|'overlay'|'lua'|'test', kind: 'state'|'command'|'hello'|'overlay-status', nonce: string, payload: unknown }`. Non-conforming CustomEvents are ignored silently.
- Storage keys: `lc.session.v1`, `lc.presets.v1`, `lc.snapshot.v1`, `lc.settings.v1`, `lc.log.v1` (localStorage); persistent-data slots `live-counter/session`, `live-counter/presets` (realm GLOBAL). Conflict rule on load: higher `revision` wins between localStorage and the mirror. Loaded `status` is STORED state — never re-derived (Phase 1 ledger rule).
- Every dock UI action dispatches through `SessionController.dispatch` (one writer); `duplicate-nonce` rejection enforced there via `NonceWindow`.
- Timer wiring rules (Phase 1 ledger): controller stops the timer on a `completed` effect AND dispatches `pause` on a rejected `tick`; the `running`/`firing` conflation gets its one-line fix in Task 2.0.
- Dock Live view: primary controls ≥ 44 px, fully usable at 300 px width, no hover-dependent controls; status never colour-only; WCAG 2.2 AA contrast.
- Overlay: template text rendered via `textContent` (never innerHTML); tabular numerals; first paint gated on `document.fonts.ready`; animations use only `transform`/`opacity` via WAAPI with explicit cancel-then-start interrupt semantics.
- TDD per task; `npm test` (vitest), `npm run test:ui` (Playwright), `npm run typecheck`, `npm run build` all green at each commit that claims them.

## PRD amendments this plan implements (PRD.md is edited alongside this plan)

1. **§8.1/§8.5 `hiddenByCompletion`:** Session gains `hiddenByCompletion: boolean`; the engine itself hides on completion when kind is `hide` (sets `overlayVisible:false`, `hiddenByCompletion:true`, emits overlay effect); `holdThenHide` hides via a new dock-internal `completionHide` command after N seconds; exit-from-complete re-shows **iff `hiddenByCompletion`**; operator show/hide clears the flag. This closes the Phase 1 parked residual exactly per PRD intent ("if completion had hidden the overlay").
2. **§7.1/§10.4 overlay credentials:** the overlay URL embeds `?port=<p>&pw=<password>` (generated by the dock's setup screen). Rationale: the overlay authenticates to obs-websocket but has no input UI; the URL lives in OBS's scene collection on local disk — the same trust domain where OBS itself stores that password in plaintext (`plugin_config/obs-websocket/config.json`, verified Phase 0).
3. **§8.4 timer contract:** dock pauses on rejected tick and stops the timer on completion (engine-correct spin documented in Phase 1).

## Locked interfaces

```ts
// src/shared/store.ts
export function createStore<T extends object>(initial: T): {
  get(): T; set(patch: Partial<T>): void; subscribe(fn: (s: T) => void): () => void };

// src/protocol/obsws-client.ts
export interface ObsWsOptions { url: string; password?: string; eventSubscriptions: number;
  backoffMs?: [min: number, max: number] }           // default [1000, 10000], exponential ×2
export class ObsWsClient {
  constructor(opts: ObsWsOptions);
  connect(): void; close(): void;
  readonly state: 'connecting' | 'identified' | 'closed' | 'auth-failed';
  request(type: string, data?: object): Promise<Record<string, unknown>>;  // rejects on timeout(8s)/close
  on(ev: 'identified' | 'closed' | 'auth-failed', fn: () => void): () => void;
  onEvent(fn: (eventType: string, eventData: Record<string, unknown>) => void): () => void;
}

// src/protocol/bus.ts
export type BusKind = 'state' | 'command' | 'hello' | 'overlay-status';
export interface BusMessage { app: 'live-counter'; v: 1; source: 'dock'|'overlay'|'lua'|'test';
  kind: BusKind; nonce: string; payload: unknown }
export class Bus {
  constructor(client: ObsWsClient, source: BusMessage['source']);
  send(kind: BusKind, payload: unknown): Promise<void>;         // generates nonce
  onMessage(fn: (m: BusMessage) => void): () => void;           // validated envelopes only, own-source filtered out
}

// src/protocol/persistence.ts
export interface StorageLike { getItem(k: string): string | null; setItem(k: string, v: string): void; removeItem(k: string): void }
export interface LoadOutcome<T> { value: T | null; warning: 'corrupt-quarantined' | 'mirror-used' | null }
export interface OverlaySnapshot { template: string | null; value: number; style: StyleConfig; schemaVersion: 1 }
export interface DockSettings { wsPort: number; wsPassword: string; schemaVersion: 1 }   // defaults 4455, ''
export class DockStorage {
  constructor(local: StorageLike, client: ObsWsClient | null);   // client null → no mirror (tests)
  loadSession(): Promise<LoadOutcome<Session>>;                  // localStorage vs mirror: higher revision wins
  saveSession(s: Session | null): void;                          // sync localStorage write + fire-and-forget mirror
  loadPresets(): Promise<LoadOutcome<Preset[]>>; savePresets(p: Preset[]): void;
  loadSnapshot(): OverlaySnapshot | null; saveSnapshot(s: OverlaySnapshot | null): void;
  loadSettings(): DockSettings; saveSettings(s: DockSettings): void;
  log(event: string, detail?: string): void; readLog(): string[];   // ring buffer ≤ 500 entries in lc.log.v1
}

// src/dock/controller.ts
export interface Scheduler { schedule(ms: number, fn: () => void): unknown; cancel(h: unknown): void }
export interface ControllerState { session: Session | null; snapshot: OverlaySnapshot | null;
  lastAction: { label: string; value: number } | null;           // feeds the "+1 ✓ 24" flash
  recovered: boolean }                                            // true when restored from storage this boot
export class SessionController {
  constructor(deps: { storage: DockStorage; bus: Bus; timer: AutoTimer; scheduler: Scheduler; nowMs?: () => number });
  init(): Promise<void>;                                          // load session/snapshot, restore Paused, broadcast, start heartbeat(2s)
  startSession(cfg: SessionConfig, style: StyleConfig, template: string | null): void;
  dispatch(cmd: Command): ApplyResult;                            // nonce-dedup → applyCommand → effects → persist → broadcast
  getState(): ControllerState; subscribe(fn: (s: ControllerState) => void): () => void;
}
```

**`dispatch` effect handling (the contract):** `completed` → `timer.stop()`; if kind `holdThenHide` → `scheduler.schedule(seconds*1000, …dispatch completionHide if still complete)`; any accepted count-change that exits complete cancels that pending schedule. Rejected `tick` inside the timer's onTick → `dispatch({type:'pause'…})`. `session-ended` → if `keepOverlay`, `saveSnapshot({template, value, style})`; session set to null, persisted, broadcast. `start`/`resume` accepted → `timer.start(intervalSeconds, hooks)`; `pause`/`setMode`-to-manual accepted → `timer.stop()`; `faster`/`slower` accepted with changed interval → `timer.setIntervalSeconds`. Every accepted command: `storage.saveSession` then `bus.send('state', …)`.

**State broadcast payload:** `{ session: Session | null, snapshot: OverlaySnapshot | null, style: StyleConfig | null, template: string | null, heartbeat: number }` — the overlay renders from this alone.
