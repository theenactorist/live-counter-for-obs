Live Counter — Setup

This page shows the exact addresses for the Live Counter files on THIS computer, so you can add them to OBS without typing anything by hand. It makes no network connection of its own — it just reads its own address and shows the two sibling files next to it.

Dock URL

Add this in OBS: Docks → Custom Browser Docks.

Overlay URL

Add this in OBS as a Browser Source. This link never carries your websocket password.

Setup steps

  1. In OBS: Tools → WebSocket Server Settings → enable the server. Note the port and password — leave authentication ON.
  2. In OBS: Docks → Custom Browser Docks → add a dock using the Dock URL above.
  3. In the dock: open the Diagnostics tab and paste the websocket password there.
  4. In OBS: add a Browser Source pointing at the Overlay URL above — or open the dock's Diagnostics tab and click "Add overlay to my scene" to do this automatically, with the recommended settings already applied.
    Recommended Browser Source settings:
    • Width / Height = your canvas (base) resolution
    • FPS: 30 (or 60 to match your project)
    • "Shutdown source when not visible": unchecked
    • "Refresh browser when scene becomes active": unchecked
  5. In OBS: Tools → Scripts → add counter-hotkeys.lua, then assign keys in Settings → Hotkeys.
